# Assets

Every third-party asset in the game, with its source and licence. Anything not
listed here was made in code for this project (procedural textures, models and
the generated placeholder audio) and needs no entry.

| Asset | Files | Source | Licence |
|---|---|---|---|
| Orbitron (Black 900) | `assets/fonts/orbitron_900.woff2` | The League of Moveable Type, github.com/theleagueof/orbitron | SIL OFL 1.1 (`assets/fonts/LICENSE_orbitron.txt`) |
| Jersey 10 | `assets/fonts/jersey_10.ttf` | The Soft Type Project Authors (Google Fonts), github.com/scfried/soft-type-jersey | SIL OFL 1.1 (`assets/fonts/LICENSE_jersey_10.txt`) |
| Michroma | `assets/fonts/michroma.woff2` | Vernon Adams, github.com/googlefonts/Michroma-font | SIL OFL 1.1 (`assets/fonts/LICENSE_michroma.txt`) |

Their licence texts, with Godot's, are collected into `THIRD_PARTY_NOTICES.txt`
by `tools/make_notices.gd`, which ships next to the game. A new asset with a
licence file goes in that script's `SHIPPED` list too.

## Made in code (no licence needed)

- Sound effects and ambience in `assets/audio/`: generated by `tools/gen_audio.py`. **Placeholder.**
- Music in `assets/music/`: generated by `tools/gen_music.py`. **Placeholder.**
- Textures: generated at runtime by `scripts/tex_gen.gd`.
- The game icon (`icon.svg`, `installer/icon.ico` via `tools/make_icon.py`). **Placeholder.**
