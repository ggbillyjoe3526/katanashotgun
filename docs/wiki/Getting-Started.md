# Getting Started

## Download

Every version is published on the
[Releases page](https://github.com/ggbillyjoe3526/katanashotgun/releases).
Pick the newest one and download the file for your computer:

| File | For |
| --- | --- |
| `KatanaShotgun-<version>-Windows-Setup.exe` | Windows: an installer with a Start menu shortcut and an uninstaller. **Start here.** |
| `KatanaShotgun-<version>-Windows-Portable.zip` | Windows without installing: unzip anywhere and run `KatanaShotgun.exe`. |
| `KatanaShotgun-<version>-Linux.zip` | Linux (x86_64). |
| `KatanaShotgun-<version>-macOS.zip` | macOS. |

If the Releases page is empty, no version has been published yet. Check the
[Patch Notes](Patch-Notes) to see what the next one will bring.

## Install on Windows

1. Double-click the `...-Windows-Setup.exe` file you downloaded.
2. Windows may show a blue box saying **"Windows protected your PC"**. This
   appears because the game is new and not yet signed with a paid
   certificate, not because anything is wrong. Click **More info**, then
   **Run anyway**.
3. Follow the installer. You can tick **Create a desktop shortcut**.
4. Start **KATANA SHOTGUN** from the Start menu or the desktop.

To remove it, use **Uninstall KATANA SHOTGUN** in the Start menu or
Windows' *Apps* settings. Your saves are kept (see
[Saving and Continuing](Saving-and-Continuing)).

## Your first run

1. The game opens full screen at your screen's resolution. **Click** to
   start.
2. Wave 1 is gentle. Fight with both hands: **left mouse** swings the
   katana, **right mouse** fires the arc shotgun.
3. Katana kills charge the shotgun's **cells** (the ammo). Blasts
   **stagger** enemies. When an enemy is staggered and close, a gold
   **F GLORY KILL** prompt appears: press **F** for a finisher that heals
   you and refills cells.
4. Clear a wave and a score tally pays out. Every third wave is a
   [boss](Bosses).
5. Level up during the run and pick one of three
   [level-up cards](Level-Up-Cards). Cards that work together form
   [builds](Builds).
6. When you fall, the results screen counts XP into your
   [Player Level](Player-Level-and-Rewards). Press **R** to retry the same
   [seed](Seeds), or click for a new one.

Next: the full [Controls](Controls) and [How to Play](How-to-Play).

## What it runs on

The game aims to run at a steady 60 frames per second on a 2015-era laptop
with integrated graphics, and much faster on gaming PCs. If it struggles,
lower the **Quality** preset or **Render scale** in [Settings](Settings).
