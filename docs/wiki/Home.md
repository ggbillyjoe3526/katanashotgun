# KATANA / SHOTGUN

**A chrome-armed ronin, a thermal katana in the left hand, an arc shotgun in the
right, and endless neon rooftops full of gangs.** KATANA / SHOTGUN is an
arcade first-person horde shooter set in Shin-Kagura, a cyberpunk Japanese
megacity under a striped synthwave sun.

The blade charges the gun, and the gun sets up the blade. Blast an enemy to
stagger it, slash it, press **F** for a brutal glory kill, refill your cells
and do it again. Every run is seeded, a boss arrives every third wave, and a
Player Level that never resets shows how far you've come.

## Where the game is today

KATANA / SHOTGUN is in early development, version **0.1 Dev 2**. Everything on
these pages describes the game as it is built today. Things still being
built are marked **Coming soon**, and numbers can change as the game is
tuned. The game runs on Windows first, with Linux and macOS builds too.
