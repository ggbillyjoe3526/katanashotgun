# Seeds

Every run has a **seed**, shown as eight characters like `1A2B-3C4D` on the
pause screen, the results screen and the high-score table.

## What the seed decides

- The map, its colour palette and the weather
- Where the cover (crates and obelisks) sits on the roof
- Every wave's line-up and where enemies drop in
- Which [mutators](Waves-and-Mutators) come up
- The order the [bosses](Bosses) arrive in
- The [level-up cards](Level-Up-Cards) you're offered
- The order of the music

**The same seed always gives the same run.** If you play the same way, the
same things happen. A friend on your seed faces exactly the same waves,
mutators, bosses and card offers, so you can race each other on score.

Your Player Level and unlocked weapon looks don't change anything in a run,
so seeded scores stay comparable.

## Playing a seed again

- On the results screen, press **R** to retry the same seed.
- Click instead for a new, random seed.

## Playing a friend's seed

There's no box to type a seed into yet. Until there is, you can start the
game on a seed from a shortcut (Windows):

1. Right-click your **KATANA SHOTGUN** desktop shortcut and choose
   **Properties**.
2. In **Target**, after the closing quote, add a space and then
   `-- --seed=1A2B-3C4D` (with your friend's seed).
3. Click **OK** and start the game from that shortcut.

The first run you start plays that seed. Remove the text again to go back to
random seeds.
